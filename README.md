# Электронный тематический словарь архангельских говоров

Интерактивный словарь диалектной лексики Архангельской области с возможностью поиска, фильтрации и визуализации на карте.

[🔗 Электронный тематический словарь архангельских говоров](https://arkhdialect.narfu.ru/)

## О проекте

Проект реализован в рамках гранта Российского научного фонда № 23-28-01380 «Тематический словарь архангельских говоров с электронной поддержкой».

Словарь содержит диалектную лексику, сгруппированную по тематическому принципу. Сейчас выделены категории:
- Одежда, обувь, головные уборы, украшения, ткани
- Жилые и хозяйственные постройки и их части
- Традиционные северные блюда и напитки

## Основной функционал

- Поиск слов по алфавиту и частичному совпадению
- Фильтрация по:
    - тематическим подкатегориям
    - районам Архангельской области
    - частям речи
- Лексический атлас

## Скрипты

Пайплайн наполнения словаря — папка `scripts/` 

- `scripts/parse_dictionary.py` — парсер тома словаря: сырой текст → `json` (рубрики → леммы → грамматика → значения → примеры по районам → производные формы и перекрёстные ссылки). Пути задаются аргументами:
  ```bash
  venv/Scripts/python -X utf8 scripts/parse_dictionary.py [dicN_raw.txt] [parsed_dictionary_N.json]
  ```
 В конце печатает сводку и подозрительные строки для ручной проверки.
- `scripts/migrate_to_db.py` — заливает `json` в `dialect.db` 
  ```bash
  venv/Scripts/python -X utf8 scripts/migrate_to_db.py [parsed_dictionary_N.json]
  ```
- `scripts/create_concept_tables.py` — создаёт таблицы графа понятий `Concept`/`Concept_Sense` в `dialect.db`.

Пересборка графа понятий после перезаливки словаря: `venv/Scripts/python manage.py build_concepts`.
